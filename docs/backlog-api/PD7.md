# PD-7: Productive Chains (NCM, câmbio)

**Duração**: a dimensionar  
**Prioridade**: 🟢 P3  
**Trilha**: Dados Públicos Territoriais  
**Depende de**: iniciativa de produto tipo “cadeias produtivas” / cooperativas exportadoras  
**Status**: ⏳ Pendente — **fora do núcleo** até existir produto

## Contexto

NCM e câmbio apoiam comércio especializado, não o MVP territorial.

## Escopo potencial

- NCM como classificação **informativa** (não orientação fiscal definitiva)
- Câmbio como **módulo/plugin** opcional (turismo, exportação)

## Fora do escopo

- Núcleo Territory/Membership
- Taxas financeiras genéricas / crédito sem produto (FASE61 etc.)
- Substituição de contador/fiscal

## Critérios de aceite (quando ativado)

- [ ] Zero impacto se flag off
