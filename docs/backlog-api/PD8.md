# PD-8: Digital Presence (Registro.br)

**Duração**: a dimensionar  
**Prioridade**: 🟢 P3  
**Trilha**: Dados Públicos Territoriais  
**Depende de**: páginas públicas / hub de serviços ([FASE26](./FASE26.md)) · possível open-core ([FASE55](./FASE55.md))  
**Status**: ⏳ Pendente — extensão / premium

---

## Contexto

Iniciativas locais podem querer domínio `.br` e página pública — não é núcleo do pertencimento territorial.

## Escopo potencial

```text
Perfil territorial → catálogo → página pública → consultar domínio → conectar domínio próprio
```

- Consulta Registro.br via port dedicado
- Sugestão de domínio
- Conexão de domínio (ops/DNS) como serviço premium

## Fora do escopo

- Núcleo de membership / feed / mapa
- Registrar domínio em nome do usuário sem processo comercial claro

## Critérios de aceite (quando ativado)

- [ ] Consulta via backend + cache
- [ ] Fluxo opt-in
- [ ] Falha externa não impede página no domínio Arah
